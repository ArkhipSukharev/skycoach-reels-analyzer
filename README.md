# Skycoach Reels Analyzer

Веб-сервис, который по ссылкам на Instagram Reels собирает метрики ролика и определяет,
есть ли в нём реклама Skycoach, насколько она заметна и правильно ли размещён баннер.

- До 20 ссылок за раз, обработка в фоне, результаты появляются в таблице по мере готовности.
- Для каждого ролика: автор, дата, просмотры, лайки, комментарии; класс интеграции 0/1/2;
  заметность 1–5 с обоснованием в секундах и процентах кадра; проверка размещения баннера
  по правилам прошлых выплат (обрезан, мелкий, под интерфейсом, не виден).
- Повторная отправка той же ссылки не запускает обработку заново, а отдаёт готовый результат
  с пометкой **«Дубликат проверки»**.
- Две вкладки:
  - **Новый анализ** — только ваши отправки в этой сессии браузера; фильтры по колонкам
    (статус, автор, просмотры, лайки, комментарии, класс, заметность).
  - **База проверок** — общая история в Postgres; по умолчанию только успешные (`done`),
    ошибки — через фильтр статуса. Фильтры: автор, даты, просмотры, лайки, статус.
- LLM по умолчанию — **Gemini 3.8 Flash через AI Tunnel** (OpenAI-совместимый API, оплата в ₽).
  Каскад дешёвой модели выключен (`GEMINI_CASCADE=false`); при необходимости включается в `.env`.

## Запуск

Нужен только Docker (Docker Desktop на Windows/macOS).

```bash
git clone <repo> skycoach-reels
cd skycoach-reels
cp .env.example .env        # вписать GEMINI_API_KEY (AI Tunnel) и APIFY_TOKEN
docker compose up -d --build
```

- Интерфейс: <http://localhost:8000>
- Публичная ссылка — Cloudflare Quick Tunnel; смотреть в логах API:
  `docker compose logs api | grep "PUBLIC URL"`
  или `GET /api/health` → поле `public_url`.

> **Windows:** путь к папке проекта должен быть латиницей. BuildKit не собирает образ из папки
> с кириллицей в пути. Если переименовать папку нельзя, подключите её как диск:
> `subst S: "D:\Папка проекта"` и запускайте `docker compose` из `S:\`.

Остановить: `docker compose down` (данные Postgres сохраняются), `docker compose down -v`
(очистка базы и рабочей папки кадров). Тесты:
`docker compose run --rm --no-deps api python -m pytest -q`.

### Ключи

| Переменная | Где взять | Зачем |
|---|---|---|
| `GEMINI_API_KEY` | [aitunnel.ru](https://aitunnel.ru) (рекомендуется), Google AI Studio или ProxyAPI | Кадры, речь, классификация |
| `GEMINI_BASE_URL` | `https://api.aitunnel.ru/v1` для AI Tunnel; пусто для Google; `https://api.proxyapi.ru` для ProxyAPI | Адрес LLM API |
| `LLM_API_STYLE` | `openai` / `google` / `auto` | `openai` — chat/completions (AI Tunnel); `google` — SDK google-genai; `auto` угадывает по ключу/URL |
| `APIFY_TOKEN` | [console.apify.com](https://console.apify.com/settings/integrations) | Метрики и прямые ссылки на видео/звук |

Для России удобнее всего AI Tunnel: OpenAI-совместимый формат, рубли, VPN не нужен.
Код умеет и Google SDK (ProxyAPI / прямой Google), если указать соответствующий ключ и стиль API.

Без `APIFY_TOKEN` сервис пробует yt-dlp (нестабильно). Без `GEMINI_API_KEY` метрики собираются,
но анализ завершается понятной ошибкой.

### Полезные настройки `.env`

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `GEMINI_MODEL` | `gemini-3.8-flash` | Основная модель |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.5-flash,gemini-3.1-flash-lite` | Запас при 404/перегрузке |
| `GEMINI_CASCADE` | `false` | Сначала cheap-модель на кадрах, при пограничном результате — сильная |
| `PREP_CONCURRENCY` | `0` (= до 20) | Параллельность fetch/download/prepare |
| `AI_CONCURRENCY` | `3` | Сколько роликов одновременно в detect/classify (очередь к LLM) |
| `GEMINI_MAX_CONCURRENCY` | `3` | Лимит одновременных запросов к LLM внутри воркера |
| `GEMINI_PRICE_*` | `150` / `750` / `₽` | Оценка стоимости в UI (AI Tunnel Flash) |

## Архитектура

```
Браузер ──► api (FastAPI) ──► Postgres: videos, jobs ◄── worker
   ▲                                                        │
   └── tunnel (cloudflared) — публичный HTTPS               ├─ prep-пул: Apify → скачивание → ffmpeg
                                                            └─ ai-пул (≤3): LLM кадры → LLM речь/класс
                                                               scoring.py: секунды, площади, баллы
```

Конвейер по этапам: `fetch → download → prepare → detect → classify`.
Пока один ролик в LLM, другой может уже качать метрики и кадры.

- **Очередь** — Postgres (`SELECT … FOR UPDATE SKIP LOCKED`), без Redis/RabbitMQ.
- **Дедупликация** по shortcode. Новая отправка создаёт `jobs`, но ссылается на тот же `videos`
  с пометкой «Дубликат проверки». Окончательные ошибки (удалён и т.п.) тоже сохраняются;
  временные (сеть, перегрузка) при повторе снова ставят ролик в очередь.
- **Надёжность.** До 3 попыток с паузой; запасные модели при сбое основной; зависший
  `processing` возвращается в очередь через `STALE_JOB_MINUTES` (по умолчанию 8).
  Рабочие файлы воркера на volume `workdata`, чтобы recreate контейнера не стирал кадры/аудио.
- **База проверок** по умолчанию отдаёт только `status=done` (`GET /api/videos`).

### Как считается результат

1. **Метрики** — Apify (`apify/instagram-scraper`). Просмотры = `videoPlayCount`.
   Если Instagram не отдал значение — в таблице «недоступно», не 0.
2. **Кадры** — ffmpeg, до 2 к/с (не больше 120). Detect: эталоны логотипа + кадры → JSON
   (виден ли бренд, рамка, обрезка, текст/промокод). При `GEMINI_CASCADE=true` сначала
   `gemini-3.1-flash-lite`, при пограничном результате — перепроверка на основной модели.
3. **Звук** — дорожка + описание + тексты с экрана → расшифровка, упоминания, CTA, класс 0/1/2.
4. **Числа считает код** (`app/pipeline/scoring.py`), не модель:
   - время в кадре = кадры с логотипом × интервал; отрезки появлений;
   - площадь рамки в % кадра, положение, доля обрезанных кадров;
   - перекрытие зон UI Reels (верх, низ, кнопки справа).
5. **Заметность 1–5** = 1 базовый + до 2 за время (≥20% или ≥5 с — +1; ≥50% или ≥15 с — +2)
   + 1 за крупный размер (≥6% в среднем или ≥25% в пике) + 1 за голосовой/текстовый CTA.
   При классе 0 заметность не показывается («не применимо»).
6. **Размещение** — обрезан / под UI — вычет 20%; слишком мелкий (&lt;3.5%) — 30%;
   мелковат (3.5–6%) — 20%; не виден — не засчитывать. Калибровка:
   `test_calibration_examples_from_payouts`. Пересчёт без LLM:
   `docker compose exec worker python -m app.rescore`.

## Внешние сервисы и стоимость

| Сервис | Для чего | Цена | На 1 ролик |
|---|---|---|---|
| Apify `instagram-scraper` | метрики, ссылки на видео/звук | ~$0.0027 / результат | ~$0.003 |
| Gemini 3.8 Flash через AI Tunnel | кадры + звук + класс | 150 ₽ / 750 ₽ за 1M токенов | порядка единиц–десятков ₽ |
| Cloudflare Quick Tunnel | публичный HTTPS | бесплатно | — |

Фактическая стоимость ролика — в «Подробнее» (токены + `cost_rub` от провайдера, если есть).

**Почему Apify.** Instagram с IP дата-центров часто не отдаёт видео; Apify даёт метрики и CDN-ссылки
за доли цента. yt-dlp — запасной путь.

**Почему Gemini через AI Tunnel.** Одна модель на картинки и аудио, JSON-ответ, оплата в рублях
без VPN. При `LLM_API_STYLE=openai` клиент ходит в `/v1/chat/completions`.

## Ограничения

- Только Instagram Reels/посты с shortcode. YouTube, TikTok, Facebook — отказ с пояснением.
- Невалидный shortcode создаёт запись `videos`, затем падает в `failed` (в базе по умолчанию не видна).
- Время в кадре — с точностью до интервала кадров (обычно 0.5 с).
- Рамки логотипа даёт LLM: на мелких/полупрозрачных возможны пропуски.
- Quick Tunnel меняет URL при перезапуске контейнера `tunnel`.
- Модель не детерминирована: секунды логотипа могут чуть плавать, вердикт обычно стабилен.
- Очередь к LLM ограничена (`AI_CONCURRENCY=3`): остальные ролики ждут на этапе detect/classify.
- Миграций схемы нет: таблицы создаются при старте (`create_all`).
